# REQUIRED LIVE TESTS

## Authentication

```text
POST /api/auth/login
empty payload → 400
invalid credentials → 401
valid credentials → 200

GET /api/auth/me
valid token → 200
invalid token → 401
no token → 401
```

كرر `/api/auth/me` بترتيب مختلف للـ tokens للتأكد أن cache لا يعيد response مستخدم آخر.

يجب أن يظهر:

```text
Cache-Control: no-store, private
```

---

## Conversations

بدون authentication:

```text
GET /api/conversations
→ 401/403

GET /api/conversations/1/messages
→ 401/403
```

ثم اختبر جلسة العميل المسموح بها، وتأكد أن العميل يستطيع فقط الوصول إلى محادثته.

---

## Container routes

تحقق من:

```text
/containers/debris
/containers/waste
/containers/contract
```

يجب ألا يكون:

```text
200 + Homepage + canonical /
```

بل صفحات الفئات الفعلية مع:

* correct title
* correct H1
* correct canonical
* correct metadata
* correct JSON-LD
* unique content

---

## Soft 404

```text
/definitely-not-a-real-page-2026/
```

يجب أن يرجع:

```text
404
```

وليس:

```text
200 Homepage
```

---

## Al-Shifa

اختبر:

```text
/areas/حي-الشفا/
/areas/al-shifa/
```

يجب ألا ينتجا redirect مشوهًا.

يجب أن يصل الطلب إلى صفحة حي الشفا الصحيحة، مع الحالة المقصودة للـ robots/canonical.

---

## Articles

```text
/articles
/articles/
```

يجب أن يعمل redirect المقصود إلى `/blog` إذا كان هذا هو الإصلاح المعتمد.

ممنوع:

```text
200 Homepage
```
