# 2. AUTH — بدون Cache-Buster

اختبر مباشرة على:

```text
https://sabaik.net/api/auth/login
```

### Login

```text
empty payload → 400
invalid credentials → 401
valid credentials → 200
```

ثم:

```text
GET /api/auth/me
```

اختبر:

* valid token → `200` وهوية المستخدم الصحيحة
* invalid token → `401`
* بدون token → `401`

### أهم اختبار

**لا تستخدم query parameters أو cache-buster.**

اختبر tokens مختلفة بالتتابع:

```text
Token A → User A
Token B → User B
Invalid Token → 401
Token A مرة أخرى → User A
```

وتحقق أن كل response يعود للمستخدم الصحيح.

يجب أن يكون:

```text
Cache-Control: no-store, private
```

إذا كان token خاطئ يرجع هوية مستخدم آخر بسبب caching → **P0 FAIL**.

# 3. CONVERSATIONS

اختبر بدون authentication:

```text
GET /api/conversations
GET /api/conversations/1/messages
```

المطلوب:

```text

```

وليس:

```text
200 []
```

ثم اختبر صلاحيات الأدوار الموجودة.

تأكد أن:

* المستخدم المصرح له يرى ما يجب أن يراه فقط.
* المستخدم غير المصرح له يحصل على `403`.
* بدون authentication يحصل على `401`.
* لا توجد PII أو رسائل خاصة مكشوفة.
