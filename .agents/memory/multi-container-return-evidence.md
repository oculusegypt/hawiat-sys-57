---
name: إرجاع الحاويات المتعددة وإثبات السائق
description: قواعد التحقق الذري وربط إثبات السائق بكل حاوية مرتجعة.
---

في مهمة الإرجاع متعددة الحاويات، تحقّق من أهلية كل عقد وأصل حاوية مرتبطين قبل حفظ أي تغيير. إذا فشل عنصر واحد، ارفض العملية كاملة بلا تحديث جزئي. عند النجاح، حدّث كل عقد إلى «مرتجع» وكل أصل إلى «متاح»، وأنشئ حركة منفصلة لكل حاوية تحمل إثبات السائق وبيانات الموقع.

**Why:** طلب المستخدم أن يُفحص كل عقد في الإرجاع المتعدد، وأن تصبح الحاويات متاحة، مع حفظ إثبات السائق لكل إرجاع.

**How to apply:** حافظ على هذا السلوك متطابقاً في خادم Node وواجهة PHP المستضافة، واختبر الرفض بلا تغييرات جزئية وحفظ الإثبات لكل حركة.
